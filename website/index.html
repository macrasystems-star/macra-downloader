What it does

Multi-connection speed

Splits each download into 1–32 parallel HTTP range requests to make full use of your bandwidth.

Pause & auto-resume

Every download is saved. Close the app or lose power, and it picks up where it left off on the next launch.

Video sites

Paste a link from one of ~1000 supported video sites (via yt-dlp) and get a single file with a live progress bar.

Torrents & magnets

Open magnet links and .torrent files directly, with the same speed and ETA display as normal downloads.

Clipboard capture

Copy a link anywhere and the download starts on its own. You can switch this off with one checkbox.

Private by design

No accounts, telemetry or ads. Your download history stays in a local file on your PC.

Download

Windows

Installer for Windows 10 and 11 (64-bit). It adds a Start-menu shortcut and an uninstaller, and doesn't need administrator rights.

MacraDownloader-Setup-x64.exe

"Windows protected your PC"? This appears for new apps that aren't code-signed yet. Click More info → Run anyway. If you want to check the file, compare it with SHA256SUMS.txt:

Get-FileHash .\MacraDownloader-Setup-x64.exe

Linux

A single self-contained executable for x86-64 distributions (Ubuntu 22.04+, Mint, Debian, Fedora…).

macra-downloader-linux-x64

Make it executable, then run it:

chmod +x macra-downloader-linux-x64
./macra-downloader-linux-x64

Or install from source: see the README.

Optional: install FFmpeg (winget install ffmpeg / sudo apt install ffmpeg) to get the highest-quality video downloads. Without it the app picks the best single-file format.

FAQ

Is it really free?

Yes. It's open-source software under the MIT License, with no ads, trials or paid tiers. You can read, change and share the source code.

Why does Windows or my antivirus warn me?

New programs that aren't signed with a paid code-signing certificate get a SmartScreen warning until enough people have downloaded them. The installer is built automatically and in public by GitHub from the published source code, and each release lists SHA-256 checksums so you can verify your copy.

Where is my download history stored?

On Windows: %LOCALAPPDATA%\MacraDownloader\downloads.db. On Linux: ~/.local/share/download_manager/downloads.db. Nothing is sent anywhere.

Can it open magnet links from my browser?

Yes. On Windows, tick "Open magnet: links" during installation. On Linux, install.sh registers the handler.

How do I uninstall it?

Windows: Settings → Apps → Macra Downloader → Uninstall. Linux: delete the file, or run uninstall.sh if you used the installer script.
